# CS2 Tier-1 → Telegram дайджест

Tier-1 CS2 тоглолтын үр дүн болон хуваарийг 12 цаг тутам Telegram суваг руу
монгол хэлээр илгээнэ.

**Эх сурвалж: [bo3.gg](https://bo3.gg) нээлттэй JSON API.**
HLTV нь Cloudflare-аар хамгаалагдсан бөгөөд GitHub Actions-ийн IP-г `HTTP 403`-аар
хаадаг тул ашиглах боломжгүй байсан. bo3.gg нь ижил өгөгдлийг (багууд, оноо,
тэмцээн, шат, эхлэх цаг) API хэлбэрээр өгдөг.

## Юу илгээх вэ

- Сүүлийн **12 цагт** дууссан тоглолтын үр дүн (оноо, тэмцээн, шат, формат)
- Дараагийн **24 цагт** болох тоглолтын хуваарь — УБ цагаар
- Тоглолт бүрийн шат (Playoffs, Group Stage гэх мэт)
- Тоглолт эхэлсэн байвал 🔴 LIVE тэмдэглэгээ

Шүүлтүүр: bo3.gg-ийн **S зэрэглэлийн тэмцээн**, эсвэл дэлхийн **top-20 баг**
оролцсон тоглолт. Тоглолт бүр bo3.gg дээрх хуудас руугаа холбоостой.

## Суулгах

### 1. GitHub repo үүсгэх

Энэ фолдер доторх файлуудыг шинэ **private** repo руу байршуул:

```
hltv_digest.py
requirements.txt
.github/workflows/hltv-digest.yml
```

### 2. Secrets тохируулах

Repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

| Нэр | Утга |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather-аас авсан токен |
| `TELEGRAM_CHAT_ID` | `@GamesInfo01` (эсвэл хаалттай бол `-100...`) |

> Токеныг **кодод бүү бич** — зөвхөн Secrets дотор хадгална.

### 3. Ботыг суваг/группт админ болгох

Бот тухайн чат руу мессеж бичих эрхтэй байх ёстой ("Post messages" / "Send messages").

### 4. Туршиж үзэх

Repo → **Actions** → **HLTV Tier-1 digest** → **Run workflow**.

Лог дээр `Илгээлээ (… тэмдэгт)` гэж гарвал амжилттай.

## Цагийн хуваарь өөрчлөх

`.github/workflows/hltv-digest.yml` доторх cron нь **UTC** цагаар байдаг. УБ = UTC+8:

| УБ цаг | cron (UTC) |
|---|---|
| 10:00 ба 22:00 | `0 2,14 * * *` |
| 09:00 ба 21:00 | `0 1,13 * * *` |
| 08:00 ба 20:00 | `0 0,12 * * *` |

> GitHub-ийн cron ачаалал ихтэй үед 5-15 минут хоцорч ажиллах тохиолдол байдаг.

## Тохируулах хувьсагчид

Workflow доторх `env` хэсэгт:

| Хувьсагч | Анхдагч | Тайлбар |
|---|---|---|
| `RESULT_WINDOW_HOURS` | `12` | Хэдэн цагийн үр дүнг харуулах |
| `UPCOMING_HOURS` | `24` | Хэдэн цагийн хуваарийг харуулах |
| `MAX_RANK` | `20` | Энэ зэрэглэлээс дээш багийг оруулна |
| `DRY_RUN` | — | `1` бол илгээхгүй, зөвхөн дэлгэц дээр хэвлэнэ |

## Дотооддоо туршихад

```bash
pip install -r requirements.txt
DRY_RUN=1 python hltv_digest.py
```

## Анхаарах зүйл

- bo3.gg-ийн API нь албан ёсоор баримтжуулаагүй. Бүтэц өөрчлөгдвөл засвар хэрэгтэй
  болж магадгүй, гэхдээ HTML задлахаас хамаагүй тогтвортой.
- Хариунд бооцооны мэдээлэл (`bet_updates`) ирдэг ч скрипт үүнийг бүрэн үл тоомсорлож,
  мессежид оруулдаггүй.
- Зэрэглэл нь bo3.gg-ийн өөрийн ranking бөгөөд HLTV-ийнхээс бага зэрэг зөрдөг.
