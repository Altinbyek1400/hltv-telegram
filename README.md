# CS2 Tier-1 Telegram бот

Tier-1 CS2 тоглолт бүрт тусад нь зурагтай пост Telegram суваг руу илгээнэ.

**Эх сурвалж:** [bo3.gg](https://bo3.gg) нээлттэй JSON API.
HLTV нь Cloudflare-аар GitHub Actions-ийн IP-г `HTTP 403`-аар хаадаг тул ашиглах
боломжгүй байсан.

## Постын төрлүүд

| Төрөл | Хэзээ | Агуулга |
|---|---|---|
| 📋 **Тоглолтын тов** | эхлэхээс 60 мин өмнө | багууд, огноо, цаг, тэмцээн, шат, формат |
| 🔴 **Тоглолт эхэллээ** | LIVE болмогц | багууд, тэмцээн, шууд дагах холбоос |
| ✅ **Тоглолт дууслаа** | дуусмагц | эцсийн оноо, ялагч тодоор |
| 🗓 **Өдрийн тойм** | өглөө 09:00 (УБ) | тухайн өдрийн бүх тоглолтын жагсаалт |

Эхний гурав нь тухайн тоглолтын **үүсгэсэн зурагтай** — багийн лого, оноо/цаг,
тэмцээний нэр, шат. Зураг нь `card.py` дотор Pillow-оор зурагддаг.

## Бүтэц

```
bot.py                        үндсэн логик (MODE=watch | daily)
card.py                       тоглолтын зураг үүсгэгч
state.json                    аль тоглолтыг зарласнаа санана (бот өөрөө бичнэ)
requirements.txt
.github/workflows/watch.yml   10 минут тутам
.github/workflows/daily.yml   өдөрт нэг удаа
```

## Суулгах

### 1. Repo нь public байх ёстой

`watch.yml` нь 10 минут тутам ажилладаг тул сард ~4300 минут зарцуулна.
Private repo-д үнэгүй багц зөвхөн 2000 минут — хүрэлцэхгүй.
**Public repo дээр Actions бүрэн үнэгүй, хязгааргүй.**

Токен нь Secrets дотор нууцлагдсан хэвээр байх тул кодыг ил болгоход аюулгүй.

Settings → General → доод талын Danger Zone → **Change repository visibility** → Public.

### 2. Secrets

Settings → Secrets and variables → Actions:

| Нэр | Утга |
|---|---|
| `TELEGRAM_BOT_TOKEN` | BotFather-аас авсан токен |
| `TELEGRAM_CHAT_ID` | `@GamesInfo01` эсвэл `-100...` |

### 3. Workflow эрх

Settings → Actions → General → **Workflow permissions** →
**Read and write permissions** сонгож хадгална.
Энэ нь бот `state.json`-оо буцааж commit хийхэд шаардлагатай.

### 4. Анхны ажиллагаа

Actions → **CS2 watcher** → **Run workflow**.

Эхний удаад бот **юу ч илгээхгүй** — зөвхөн одоо байгаа тоглолтуудыг
"үзсэн" гэж тэмдэглэнэ. Ингэснээр өнгөрсөн 40 тоглолтын үр дүн нэг дор
асгарахаас сэргийлнэ. Хоёр дахь ажиллагаанаас эхлэн жинхэнэ постууд явна.

## Тохируулах

Workflow доторх `env` хэсэгт:

| Хувьсагч | Анхдагч | Тайлбар |
|---|---|---|
| `TIERS` | `s,a` | `s` = зөвхөн хамгийн том тэмцээн |
| `ANNOUNCE_MINUTES` | `60` | Тов хэдэн минутын өмнө тавих |
| `MODE` | `watch` | `watch` эсвэл `daily` |
| `NO_PHOTO` | — | `1` бол зурагггүй, зөвхөн текст |
| `DRY_RUN` | — | `1` бол илгээхгүй, дэлгэц дээр хэвлэнэ |

Онцлох багийг `bot.py` доторх `SPOTLIGHT` олонлогоос өөрчилнө
(одоогоор `The MongolZ` ⭐ тэмдэгтэй гарна).

Постын давтамжийг багасгах бол `watch.yml` доторх cron-г `*/15` эсвэл
`*/20` болгож болно — гэхдээ LIVE мэдэгдэл төдий хэмжээгээр хоцорно.

## Дотооддоо туршихад

```bash
pip install -r requirements.txt
DRY_RUN=1 MODE=daily python bot.py
DRY_RUN=1 MODE=watch python bot.py
```

`DRY_RUN=1` үед Telegram руу юу ч илгээхгүй, гэхдээ `state.json` шинэчлэгдэнэ —
турших үед `STATE_PATH=/tmp/test.json` гэж зааж өгвөл дээр.

## Анхаарах зүйл

- bo3.gg-ийн API албан ёсоор баримтжуулаагүй. Бүтэц өөрчлөгдвөл засвар хэрэгтэй.
- Хариунд бооцооны мэдээлэл (`bet_updates`) ирдэг ч бот үүнийг бүрэн үл тоомсорлодог.
- GitHub-ийн cron ачаалалтай үед 5-15 минут хоцорч ажиллах тохиолдол байдаг.
- `state.json` нь автоматаар commit хийгддэг тул repo-д тогтмол шинэ commit гарна.
  Энэ нь 60 хоногийн идэвхгүй байдлын улмаас хуваарь унтрахаас ч сэргийлнэ.
